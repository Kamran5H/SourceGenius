SG VPN Controller

Auto-switches IP while Source Genius runs. Recommended backend is Proxy — deterministic, no clicking, no calibration.

Backend

Proxies (one per line, top = first used; rotates down the list on block/slow)

Format: scheme://[user:pass@]host:port. Schemes: http, https, socks5. Auth (user:pass) works for http/https proxies only — Chrome can't authenticate SOCKS from an extension. A single rotating residential endpoint (one line) is best: it changes IP itself, so "rotate" just re-applies it. Only amazon.* traffic is proxied; everything else stays direct.

Test

After "connect", open https://api.ipify.org in a new tab — the IP should be the proxy's. After "Disconnect" it returns to your real IP.
